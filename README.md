## Overview

This repository contains the source code for my personal developer and design portfolio. It was designed from scratch to reflect modern UI/UX principles, featuring a bespoke **glassmorphic design system**, custom **CSS animations**, and a highly responsive layout. 

The site serves as a central hub for my professional experience, technical skills, and featured projects (including Web3, AI platforms, and editorial design).

## Key Features

- **Premium UI/UX:** Dark-mode first design utilizing deep midnight backgrounds, electric fuchsia/violet gradient meshes, and glassmorphic (`backdrop-filter`) cards.
- **Interactive Modals:** Custom-built JavaScript modal system that injects rich experience details dynamically when timeline cards are clicked.
- **Split-Pane Showcases:** Dedicated project sections featuring split layouts with hardware-accelerated image scaling and editorial typography.
- **Performance Optimized:** Zero heavy frameworks. Everything is built natively with vanilla web technologies to ensure lightning-fast load times.
- **Intersection Observer Animations:** Smooth fade-up scroll animations triggered via native browser APIs as the user navigates the page.

## Technology Stack

- **Structure:** Semantic HTML5
- **Styling:** Vanilla CSS3 (Custom Variables, Flexbox, CSS Grid, Keyframe Animations)
- **Logic:** Vanilla ES6 JavaScript (Event Delegation, DOM Manipulation, IntersectionObserver)
- **Deployment:** GitHub Pages / Netlify / Vercel (Configurable)

## Running Locally

Because this project is built with vanilla web technologies, running it locally is incredibly simple. You don't need `npm` or any package managers.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shreyah101/shreya-portfolio.git
   ```
2. **Navigate into the project directory:**
   ```bash
   cd shreya-portfolio
   ```
3. **Open the site:**
   Simply open `index.html` in your favorite web browser, or use a tool like VS Code's **Live Server** extension to launch a local development server with hot-reloading.
